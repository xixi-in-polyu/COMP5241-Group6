What the platform includes

Each feature supports a specific part of preparing, reviewing, or completing course work.

01

Course authoring

Teachers build course content from their own materials.

  • Upload PDF, TXT, DOCX, and PPTX files
  • Review extracted knowledge and source evidence
  • Edit and publish structured mini-courses
02

Assignment builder

A four-step workspace keeps generation and review separate.

  • Select sources and knowledge coverage
  • Set question types, difficulty, and learning goals
  • Edit questions before saving and submitting
03

Interactive Labs

Teachers can add practical activities alongside regular questions.

  • Seven activity types, including matching, ordering, and quizzes
  • Up to three separately approved labs per assignment
  • Version history, updates, ordering, and archiving
04

Student learning

Published work is organised by course and assignment.

  • Read course content and supporting materials
  • Answer standard assignment questions
  • Complete approved labs as ungraded practice
05

Learning tools

Additional formats support explanation and exploration.

  • Course animation library
  • Audio explanations
  • Interactive learning experiments and workshops
06

Review and control

Generated content stays under teacher control.

  • Evidence references for generated activities
  • Draft and submitted assignment states
  • Approval required before labs reach students

Technology

The application runs on Vercel with a PostgreSQL database. This GitHub Pages site provides the public project overview and documents.
