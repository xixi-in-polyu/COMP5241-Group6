# Software Engineering Learning Platform

## Run the application
1. Install dependencies: `pip install -r requirements.txt`
2. Add a valid `OPENAI_API_KEY` to a `.env` file. You may also set `OPENAI_BASE_URL` and `MODEL_NAME`.
3. Start the app: `streamlit run app.py`

## Learning modules
- **Requirements Analysis**: Interview an AI client to discover functional requirements, quality attributes, constraints, edge cases, and operational needs. Ask explicit engineering questions to receive project-grounded mentoring on requirements, architecture, security, testing, delivery, and operations.
- **Software Engineering Reliability Lab**: Reproduce seeded defects involving duplicate event processing, object-level authorization, and deployment readiness. Compare actual and expected behavior, consider the underlying engineering concepts, and record reproducible defect reports. This module does not require an API key.
- **Requirements-to-Code Workshop**: Describe a feature, generate starter code and test guidance, edit the code in the student coding area, and submit the implementation to the AI for evidence-based correction analysis. This module requires an API key.
